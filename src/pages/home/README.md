# 공개 웹 포트폴리오

사용자가 승인한 한 페이지 시안을 정식 홈(`/`)으로 교체한 구현입니다. 내용·이미지는 기존 PDF 근거를 사용하며 PDF의 26쪽 구성은 별도로 유지합니다.

## 현재 구성

- 소개·기술 → FeedShop 소개·조회 개선·투표 동시성·회고 → 3M 소개·인증 구조 개선·회고 → 협업·AI → 관련 경험 → 마무리·연락처·자료 링크
- FeedShop은 문제 해결 2개, 3M은 문제 해결 1개입니다. 3M의 경계 분리와 인증 정보 전달은 하나의 사례 안에서 적용 단계로 설명합니다.
- 문제·대안·핵심 구조·검증·회고는 기본 노출합니다. 보조 측정과 추가 활동 근거만 펼쳐봅니다.
- 상단 기술 목록과 하단 자료 링크는 토글 없이 표시합니다. 상단 오른쪽은 PDF, 소개 영역은 LinkedIn·GitHub입니다.
- 조회 42회·2회·캐시 적중 0회 이미지는 가로 3열로 바로 표시하며 원본 비율을 유지합니다. 클릭하면 같은 페이지에서 확대합니다.
- 마무리 제목은 강제 줄바꿈 없는 한 문단입니다. 좁은 화면에서는 자연스럽게 줄바꿈합니다.
- 데스크톱에는 왼쪽 고정 프로젝트 목차, 모바일에는 상단 가로 목차를 둡니다.

## 관리 도구와 기존 링크

- 로컬 `/manage`는 이 홈을 직접 미리보기합니다. 소개·기술, 강점 소개, 프로젝트·협업·AI, 관련 경험, 마무리·기업 이해, 연락처, 자료 링크, 하단 문구를 조합합니다.
- 기본 강점은 소개에 통합한 요약입니다. 추가 검증 중심 강점은 기존 독립 선택지로 유지합니다.
- 기업별 프로젝트·문구·강점·기업 이해·블록 순서와 생성 URL을 유지합니다. FIX는 기업별 선택 시에만 나타납니다.
- 이전 전체 기본 순서로 저장된 URL은 새 기본 순서로 옮깁니다. 개별 사용자 지정 순서와 기업별 저장 초안은 보존합니다.
- 기본값 복귀는 공개 구성·프로젝트·문구·강점을 함께 복원합니다. 기업별 초안을 삭제하지 않습니다.
- `/web-preview`는 개발 환경에서 정식 홈으로 연결하는 별칭입니다. 별도 시안 소스는 보유하지 않습니다.
- 과거 `?project=feedshop`, `?project=3m`과 `#hero`, `#collaboration`, `#closing`, `#three-m` 북마크는 새 위치로 연결합니다.
- 공개 빌드에는 관리 화면을 포함하지 않습니다.

## 작업 전 → 작업 후 → 이유

| 작업 전 | 작업 후 | 변경 이유 |
|---|---|---|
| 기존 공개 홈과 별도 시안 병존 | 승인한 시안을 정식 홈으로 교체 | 한 곳에서 최신 웹을 관리 |
| 마지막 제목에 강제 줄바꿈 | 한 문단과 자연스러운 줄바꿈 | 사용자 요청 반영 |
| SQL 원본을 보조 자료에서 펼침 | 42회·2회·0회 가로 비교 | 개선 단계를 바로 비교 |
| 관리 화면의 옛 이름·순서·미리보기 | 새 웹의 이름·순서·미리보기 | 선택과 공개 결과 일치 |
| 기존 웹 전용 카드·사이드바·렌더러 유지 | 사용하지 않는 전용 코드 제거 | 이전 UI 재등장 방지 |

## 근거와 유지 기준

- 김현수 1차: 설계 그림 보존, 문제·판단·해결·결과의 읽기 흐름, 과한 색과 밀도 개선
- 김현수 2차: 이번 웹 배치에 관한 직접 조언은 해당 없음
- 원문: Downloads/01_커리어_지원/멘토링_특강/멘토링_피드백_김현수_1차.pdf 및 2차.pdf
- 통합 규칙: docs/mentor-feedback-rubric.md의 PF-01~14
- 조회 1,000명 원본의 오류 732건/49,931건 표기는 기존 시안대로 유지합니다. 속도와 오류·정합성을 혼동하지 않습니다.
- 기술·자료 토글, 별도 프로젝트 상세 이동, 3M 사례 쪼개기를 다시 도입하지 않습니다.
- 기존 홈과 사이드바를 전제로 한 과거 설명보다 사용자가 확정한 이 문서의 구조를 우선합니다.
