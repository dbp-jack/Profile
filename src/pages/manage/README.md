# 포트폴리오 작업실

canonical 로컬 주소는 `http://127.0.0.1:5174/manage`입니다. 기존 공개 웹과 같은 본문·URL 조합을 사용하며, 관리 도구 자체는 공개 빌드에서 제외됩니다.

## 사용 흐름

1. **프로젝트·구성**: 최대 두 프로젝트를 칸에서 교체하고 순서를 정합니다. 체크한 영역만 표시하며 위·아래 버튼으로 순서를 바꿉니다.
2. **소개 문구**: 소개 프로필과 강점의 상세 정도를 각각 선택합니다.
3. **지원 기업**: 기업 이름으로 시작해 기업 이해와 연결할 경험을 작성합니다. 기업별 문구는 보관·전환·삭제할 수 있습니다.
4. **검토·공유**: 선택을 검토하고 공개 URL 또는 문서용 링크를 복사합니다. 기업 지정 없이도 이름 있는 구성을 저장할 수 있습니다.

네 단계는 언제든 이동할 수 있습니다. 미리보기는 기본적으로 실제 글자 크기를 유지하고, PC·모바일 폭이나 큰 창으로 전환합니다. 좁은 화면에서는 편집과 미리보기를 번갈아 표시합니다. 기업 문구를 입력하는 동안 미리보기 이동은 300ms 동안 묶어 처리합니다.

## 저장·복원 계약

- 저장 키: `portfolio-manager-workspace-v2`. 현재 선택(`draft`), 이름 있는 구성(`saved`), 기업 문구(`companies`)를 한 번에 저장합니다.
- 새 키가 없거나 손상됐으면 기존 `portfolio-manager-*` 키를 읽습니다. 과거 키를 삭제하거나 기본값으로 덮어쓰지 않습니다.
- 기본값 복원은 현재 선택만 바꿉니다. 저장한 구성과 기업 문구는 보존합니다.
- 이름 있는 구성에는 블록·프로젝트 순서, 소개 프로필, **강점 프로필**, 기업 식별자를 저장합니다. 기업 문구는 기업별 공통 초안이며 같은 기업을 선택한 구성에서 함께 사용합니다.
- 직전 변경 취소는 현재 세션의 변경 한 번을 복구합니다. 구성·기업 문구 삭제도 취소할 수 있습니다.
- 현재 브라우저의 동일 origin에 저장합니다. 다른 브라우저·포트로 자동 동기화하지 않습니다. 공유 URL에 포함된 공개 문구는 다른 환경에서도 같은 화면을 재현합니다.
- 기업 문구의 공백을 입력 중에 제거하지 않습니다. 정규화·길이 제한은 저장 데이터 복원과 공개 URL 생성 시 적용합니다.
- 공유 URL 계약은 `src/portfolio-builder/presets.ts`와 `company-direction.ts`를 재사용합니다. 관리 상태를 공개 페이지에서 직접 읽지 않습니다.
